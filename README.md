# Leilão da Meia-Noite Online

Jogo multiplayer para 3 ou 4 pessoas com lobby público, salas persistentes, reconexão e partidas sincronizadas em tempo real.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Produção

```bash
npm run build
npm run start
```

O projeto inclui `.shardcloud` e está pronto para implantação na Shard Cloud.

## Trilha sonora

**Apparitions Ball**, de Bobjt, disponibilizada em CC0/domínio público pelo OpenGameArt.
